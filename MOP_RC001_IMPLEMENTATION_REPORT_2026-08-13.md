## Formula

$$
\text{expected\_move\_pct} = \frac{\text{atr}}{\text{entry\_price}} \times \text{rr} \times 100
$$

Where:
- `atr` = ATR(14) proxy from signal (historical data, computed before scan cycle)
- `entry_price` = live LTP at signal creation time  
- `rr` = `sig.risk_reward_ratio` (computed from target/entry/stop — all pre-signal data)

**No look-ahead**: all inputs are available at signal generation time.

## Output format

Each signal produces one JSON line in `data/mop_rc001/MOP_RC001_YYYY-MM-DD.json`:

```json
{
  "obs_id": "TATASTEEL_141523",
  "ts_utc": "2026-08-13T14:15:23Z",
  "trading_date": "2026-08-13",
  "symbol": "TATASTEEL",
  "direction": "BUY",
  "entry_price": 191.19,
  "stop_loss": 188.03,
  "target_price": 199.08,
  "atr": 2.1,
  "atr_pct": 1.0982,
  "rr": 2.5,
  "expected_move_pct": 2.7455,
  "confidence": 7.1,
  "candidate_score": 0.7234,
  "strategy": "breakout",
  "regime": "RANGE_MARKET",
  "rsi": 55.0,
  "vol_ratio": 2.4,
  "sector": "Metals",
  "observation_horizon_days": 1,
  "selected": null,
  "actual_return_pct": null,
  "no_lookahead": true
}
```

`selected` and `actual_return_pct` are `null` at creation. They are intended to be filled by post-hoc analysis after 30 days of data are collected.
